# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in this project, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to `abdulrehman.ch@live.com` detailing the vulnerability, reproduction steps, and potential impact.
3. You will receive an initial response acknowledging the report within 48 hours.
